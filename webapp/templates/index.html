Getting Started

Requirements
  • Run from a privileged workstation with network access
  • Valid gcert certificate (run gcert if expired)
  • Active admin_session with a tracking ticket
  • gcloud authenticated with your corporate account
  • The customer's SecOps Tenant ID (UUID format)
Information You'll Need
  • SecOps Tenant ID (UUID)
  • Ticket ID number
  • First Name, Last Name, Email (for SOAR provisioning)
  • Vector Account ID and Opportunity ID
  • SecOps Admin Group (IdP group for admin access)
  • License Type from contract (Standard, Enterprise, or Enterprise Plus)
  • License Expiration Date from contract
  • Customer Region requirements
